# Found Sounds

Three original short mono PCM16 sounds created for Seqvium by deterministic mathematical synthesis,
with no recordings, external samples or third-party source material. Distributed under the root
Apache-2.0 license. The package contains data only; it executes no code.

Use **Browser → Sound packs & extensions → Browse sounds**, then preview or add a sound to Rack or
Playlist. Disable the package in the same disclosure. Imported audio stays in project-managed media.
Removing this package directory from a distribution leaves the workstation usable without it.

The reproducible source is [create-found-sounds.py](../../../../tools/content/create-found-sounds.py).
Names and package version are independent of the Seqvium product version. This is a small sound pack,
not Sample Lab or a production generator.
