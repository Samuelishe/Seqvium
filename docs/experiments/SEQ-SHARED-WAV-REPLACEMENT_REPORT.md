# Shared WAV replacement

Role: Evidence for SEQ-SHARED-WAV-REPLACEMENT, alpha 0.1.7.0001.
Read when: Reviewing shared instrument replacement and its native musical verification.
Authoritative for: Observed local checks and their limits.
Not authoritative for: New sampler algorithms, project format, full regression or acoustic acceptance.

Channel Rack's **Replace WAV…** exposes existing durable target import with frozen occurrence/part
authority. One acceptance swaps the shared PCM resource and verified catalog tuning, retaining notes,
identities, release, local graphs and Mixer intent. Unknown tuning keeps the previous Root Pitch.
Cancel/error/stale authority accept no partial music. [Sample workflow](../SAMPLE_WORKFLOW.md#shared-wav-replacement)
and [UX](../UX_CONTRACT.md#implemented-shared-wav-replacement) own the implemented boundaries.

14.773 seconds CLI summary**, including six new preservation/known-or-retained tuning/history/reopen/
missing/malformed/cancelled/stale cases. The first fixture compares deserialized Mixer arrays by record
identity and fails; canonical structural comparison fixes the fixture. It does not weaken the source
preservation assertions. The previous 1235-case L3 belongs to the Song structure checkpoint; this
follow-up is L0/L1/L2 plus bounded native GUI, not another full-suite claim. Cadence advances to one.

A separate **complete native inspection passes**: production Open/Save, six musical Patterns, thirteen
used source editors, Piano Roll, Playlist and Mixer are reached with Windows input. It observes six

Artistic material, recordings, authoring helper and musical reference research
remain private, outside Git; they are not distributed test fixtures or public music resources.

The command swaps WAV recordings for an existing supported sampler. It does not switch algorithms,
infer pitch, automatically match recording level or detach a shared instrument. Explicit Root Pitch and
Mixer trim remain necessary for recordings without verified metadata or with different level. UI uses
the existing contextual menu and shared tokens; no new DSP/dependency/format gate is introduced.
BUILD advances once; no staging, commit, push or tag occurs. Acoustic judgement, pressure/platform
acceptance and wider Playlist scope remain separate.
